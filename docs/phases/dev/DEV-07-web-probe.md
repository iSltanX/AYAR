# DEV-7 — مسبار الويب وفحوص العرض الحي

> **الأمر:** «ابدأ مرحلة التطوير 7» · **المسار:** تطوير · **الحالة الحالية:** في الواجهة أعلاه

## 1. الهدف

«فحص التصميم ممكن بشرط وجود مرجع» (الخطة 3.3، البند 7). هذه المرحلة تبني المسبار الذي يعرض صفحات المشروع وإضافاته، ويقيس مطابقتها لمرجعها المعلن، وإتاحتها واتجاهها وحالاتها، ويلتقط صورها، ولا يخترع معيارًا جماليًا عند غياب المرجع.

> **تنبيه:** هذه المرحلة تفحص **واجهات مشاريع المستخدم**، لا واجهة عِيَار. فلا تحتاج تصميم عِيَار المعتمد.

## 2. متطلبات البدء

- **التبعيات:** DEV-6 مغلقة.
- **قرارات مستهلكة:** E-11 (المسبار في `utilityProcess` أو في بيئة Node مُدارة، والوضع الخفي للإضافات)، وE-21 (طريقة قياس الأداء)، وE-12 (منع كتابة اللقطات في أدوات المشروع).

## 4. السياق الملزم

- **D-26:** المسبار يملكه عِيَار، بـ Chromium الخاص بـ Playwright.
- **D-27 وFR-35:** اعتماد الصور المرجعية صريح لكل منصة ومتصفح وحجم عرض وثيم ولغة وحالة. ولا تُحدَّث تلقائيًا أبدًا.
- **الحالة «حساسة»** لا تُلتقط لها صورة أبدًا، حتى عند فشل توقعها (G-29: قاعدة الخصوصية تتقدم على «مع لقطة» في 538).
- **غياب المرجع** يعطي «ناقص إعداد» بالبند الناقص، ولا اكتشافات جمالية (AT-18).
- **axe:** النتائج غير المحسومة «يحتاج مراجعة»، ومراجعة الإتاحة البشرية ظاهرة دائمًا. والأداة وحدها لا تحدد المطابقة (S-22، S-23).
- **الشبكة:** صفحات المسبار محلية فقط افتراضيًا، والطلبات الخارجية تُمنع وتُسجَّل (AT-31: الخط من مضيف خارجي).
- **G-28:** المقارنة البصرية (pixelmatch) يملكها المسبار والمصنّف معًا: المسبار يلتقط ويقارن بمفتاح المرجع، والمصنّف يحكم. سجّل التقسيم النهائي.

## 5. المهام

1. **C-14:** إنشاء المسبار من العملية الرئيسية بطلب المحرك وفق E-11، ومنفذ الرسائل مع المحرك، ومواصفة المسبار (الأهداف: رابط خدمة، أو مجلد ثابت على 127.0.0.1، أو Storybook، أو إضافة بسياق دائم)، والحالات والمحاكاة والتوقعات، والمصفوفة (حجم العرض، والثيم، واللغة، ووسم «حساسة»)، وaxe بوسوم WCAG، واعتراض الشبكة، ومخرجات JSONL وPNG وaxe والمقاييس.
2. **الفحوص الحية:** `design.tokens.render`، و`design.fonts.render` (`document.fonts`)، و`design.rtl.render`، و`design.a11y`، و`design.a11y.review`، و`design.states`، و`design.visual`، و`beh.ext.host`، و`perf.web` (بطريقة E-21).
3. **الصور المرجعية:** `baseline.approve` بمفتاحها الكامل، والمقارنة، و«يحتاج مراجعة» للتغيير البصري.
4. **الخدمات المرافقة مع المسبار:** التشغيل قبل المعتمدين، والانتظار، والإيقاف بعدهم، والسجل دليلًا، و«تعذّر: الخدمة المرافقة لم تجهز» عند انشغال المنفذ.
5. **التقدم الصادق:** نسبة حقيقية لحالات المسبار المعروف إجماليها (FR-29).
6. **تثبيت متصفح المسبار** إجراء تجهيز صريح عبر C-11، بحجمه.

## 6. المخرجات
