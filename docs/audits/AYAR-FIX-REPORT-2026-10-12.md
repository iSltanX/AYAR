### AUD-05 — P2: الخلط بين ثبات التشغيل ونظافة Git

**السبب الجذري.** في `build.ts`: `dirty: run.state_changed === 1`، و`render.ts` يعرضها تحت «تغييرات غير ملتزمة». وثبات الملفات أثناء التشغيل لا يقول شيئًا عن نظافة Git عند البدء.

**الإصلاح.** فُصل المعنيان في العقد:
- `dirty` (تغييرات Git غير الملتزمة) = `null` دائمًا، لأن عِيَار لا يشغّل Git في المشروع (D-38) ولا يقيسها بأمان.
- `changedDuringRun` (جديد، البروتوكول 1.8) = مقياس `integ.state`.

والسطر في الصيغتين: «تغييرات غير ملتزمة: غير معروف · تغيّر المصدر أثناء الفحص: لا | نعم | غير معروف». واستُعمل المصطلح القائم `report.unknown` («غير معروف») بدل إضافة «غير معلوم».

**لماذا لا قياس.** عِيَار يقرأ فهرس Git دون تشغيله (`git-index.ts`)، لكن:
- مقارنة الشجرة بالفهرس لا تكشف التغييرات المجهّزة؛ والفهرس مقابل HEAD يحتاج قراءة كائنات Git وحزمه.
- ومرشحات Git (CRLF وLFS وclean) تعطي إيجابيات كاذبة.

فلا «نظيف» مؤكد بهذا الطريق. ويمكن لاحقًا إضافة «نعم» مؤكدة جزئيًا، بقرار.

**قبل.** `git status` يعرض ` M src/value.js`، و`dirty=false`، و«uncommitted changes: no».
**بعد.** `dirty: null`، و`changedDuringRun: false`، و«uncommitted changes: unknown · source changed during the scan: no». وفي تشغيل يغيّر ملفًا: `changedDuringRun: true`.

**الاختبار المضاف.** `report-state.test.ts` باللغتين.

### AUD-06 — P2: أمر الإعادة يفقد حدود الوسائط

**السبب الجذري.** `build.ts:425`، وسطر «شغّل محليًا» في `render.ts`، جمعا argv بمسافة و`cd ${cwd}` بلا اقتباس shell.

**الإصلاح.** `executor/command-line.ts` (`shellWord`، `shellLine`): اقتباس مفرد لكل كلمة فيها ما يوسّعه sh أو bash أو zsh أو يقسمه:
- مسافة، أو حرف عربي، أو اقتباس، أو `$`، أو backtick.
- glob، أو `~`، أو `{a,b}`، أو `=` في أول الكلمة.
- اسم برنامج فيه `=`.

و`cd` بالاقتباس نفسه (و`./` قبل اسم يبدأ بـ `-`). وخانات القوالب مثل `{targets}` تبقى مقروءة.

استُعمل في: أمر إعادة الاكتشاف، وسطر التحقق في «للنموذج»، وسطر `$` في سجل التجهيز. وفي الواجهة: `ServicesTab` (فيه زر نسخ) و`PerformancePanels` كانا يجمعان argv بمسافة، فصارا `commandLineText(argv, cwd)`. وقُوّي `shellWord` في الواجهة ضد `{a,b}` و`=`.

**قبل.** `node إثبات الفشل.mjs` → `MODULE_NOT_FOUND`، والخروج 1.
**بعد.** `node 'إثبات الفشل.mjs'` → الخروج 7 بالـ stderr الأصلي.

**الاختبارات المضافة.**
- `packages/engine/test/command-line.test.ts`: يشغّل السطر المولّد في `/bin/sh` و`/bin/bash` و`/bin/zsh` على 34 كلمة صعبة (عربية، ومسافات، واقتباسات، و`$()`، وglob، وأسطر جديدة، وRTL)، وعلى مجلدات بأسماء صعبة.
- `report-state.test.ts`: ملفان باسم عربي فيه مسافة، وباقتباسين، في مجلد باسم عربي. أمر التقرير يُنفَّذ في sh وzsh ويعطي 7 وstderr نفسه، باللغتين.

**الفجوات.**
- كتل الأوامر في شاشات الموافقة والخطة والفاحص (`commandOf`) تعرض «الاستدعاء المعتمد» (قالب فيه `{tool}`) بلا `cd`. هي للقراءة لا للإعادة، ولم أغيّر عرضها.
- أمر إعادة فحص تديره أداة عِيَار يحمل خانات القالب، فلا يُنفَّذ كما هو. هذا قائم قبل الإصلاح.
- محارف التحكم ثنائية الاتجاه تكشفها `inline()` لأمان العرض، فتغيّر النص المنسوخ.

### AUD-02 — P2: السر المعروف متعدد الأسطر لا يُنقّح عند الاستقبال

**السبب الجذري.** `redactText()` و`lineStream()` يقطعان النص أسطرًا ثم يطابقان القيم المعروفة داخل كل سطر، فلا تطابق قيمة من سطرين أبدًا عند الاستقبال. و`secondPass()` يطابق النص كله، فيكتشفها لاحقًا، فيُحجب التقرير بدل أن تُنقّح.

**الإصلاح** (`LineRedactor`):
- تُطابق القيم المعروفة متعددة الأسطر في المخزن الخام قبل تقطيعه (`#joinKnown`)، في الجزء الذي يمكن أن تكمله القطعة الجديدة فقط.
- لا يخرج سطر قد يكون بداية قيمة لم تكتمل (`#held`). الحجز أطول ذيل للمخزن هو بادئة قيمة، ومحدود بطول أطول قيمة متعددة الأسطر، ويُطلق فور افتراق التدفق عنها أو عند نهايته.
- `expandKnown()`: صيغتا LF وCRLF للقيمة متعددة الأسطر، مع بقاء صيغتي JSON والترميز.

**قبل.** النص يعود بلا تغيير و`counts={}`. وعبر المسار الكامل على `main` (`leak-reach-before.json`): القيمة في `stdout.log` وفي `ayar.db`، والتقرير وكل التصديرات محجوبة `secret_survived`.
**بعد.** `⟦redacted:env:API_TOKEN⟧` عند الاستقبال. والسجلان يحملان `⟦redacted:env:AUD_API_TOKEN⟧`، والتقريران والتصديرات تُبنى بلا القيمة (`leak-reach-after.json`).

**الاختبارات المضافة** (`redaction.test.ts`):
- حالة الفحص.
- القطع بين قطعتين وثلاث في كل موضع، وبين أسطر أخرى، وعند نهاية التدفق، ومرتين.
- CRLF، وJSON، والترميز، وداخل قيم JSON ومفاتيحها.
- حجز محدود: ألف سطر يبدأ كل منها القيمة، يخرج منها 999 فورًا.

وفي `redaction-evidence.test.ts`: المسار الكامل.

**الفجوات.**
- قيمة تطبعها الأداة بعد تحويل أسطرها (مسافة بادئة لكل سطر، أو بادئة سجل) لا تُطابق، كالقيمة أحادية السطر المحوّلة.
- حد الحجز هو أطول قيمة متعددة الأسطر في البيئة: محدود، لكنه قد يبلغ حجم شهادة PEM.
