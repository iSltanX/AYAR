# صفحة المراحل والموجات

صفحة عربية تفاعلية تعرض الموجات ومراحلها، وما يسير منها معًا، والحالة الحية لكل مرحلة، وما ينتظر دمجًا أو اعتمادًا أو تبعية. ولكل مرحلة مجلد عملها وفرعها والنموذج والجهد المقترحان وسببهما، وزرّا نسخ لأمر التجهيز وأمر البدء. ولكل موجة زر ينسخ «ابدأ الموجة X». **الأزرار تنسخ فقط ولا تنفّذ شيئًا.**

## من أين تأتي البيانات

المولّد يقرأ من Git لا من الملفات المفتوحة، فيعطي النتيجة نفسها أينما شُغّل داخل المستودع.

| ما تعرضه الصفحة | مصدره |
|---|---|
| المراحل: العناوين والأهداف والتبعيات والنطاق والنموذج والجهد | واجهة YAML في ملفات `docs/phases/` على `main` |
| الموجات وشروط بدئها وإغلاقها ومسؤول الدمج | جدول `docs/waves/README.md` على `main` بين علامتيه |
| الحالة الحية: مجهّزة، أو جارية، أو بانتظارك، أو معطّلة، أو مسلَّمة | حالة ملف المرحلة على فرعها `phase/<ID>`، وعدد commits الفرع، ونظافة مجلده، ووجود ملف التسليم |
| الإغلاق | الحالة `closed` على `main` مع وسم `<ID>-closed`. والمرحلة المغلقة دون وسم تظهر بتنبيه |
| القرارات التي تنتظر المالك | جدول القسم 2 في `docs/tracking/decisions.md` على `main` |
| تاريخ التحديث | أحدث تاريخ حالة في المراحل وفروعها وآخر قيد في سجل التقدم، ومعه لحظة التوليد والـcommit |

«متاحة» و«تنتظر قرارك» و«تنتظر تصميمًا» و«تنتظر مرحلة سابقة» و«تصير متاحة بعد الدمج» حالات **يحسبها المولّد** من التبعيات والقرارات، ولا تُكتب في أي ملف.

## التحديث

```bash
/opt/homebrew/bin/node tools/dashboard/build.mjs --check
```

```bash
/opt/homebrew/bin/node tools/dashboard/build.mjs
```

الأول يتحقق دون كتابة: كل مرجع إلى مرحلة أو قرار موجود، والحقول الإلزامية كاملة، وكل مرحلة في موجة واحدة، ولا مرحلة في موجة تسبق تبعيتها أو تساويها. والثاني يولّد الصفحة، ثم تُنشر على الرابط نفسه (في Claude Code: أداة Artifact بـ `url` المسجل أعلاه).
