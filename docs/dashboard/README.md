# صفحة الموجات

صفحة عربية تجيب عن سؤال واحد: **ما الموجة الحالية، وماذا أرسل؟** تعرض الموجة الحالية ومراحلها وحالاتها في مساري التصميم والتطوير، وما يعمل منها بالتوازي، وما يحتاج قرار المالك الآن وما سيُطلب منه أثناء الموجة، وزرًّا واحدًا ينسخ «ابدأ الموجة X» أو «تابع الموجة X». والموجات التالية والمغلقة والقرارات اللاحقة مطوية تحتها. والمسارات والفروع والنموذج والنطاق في «التفاصيل التقنية» لكل مرحلة، وهي اختيارية. **الأزرار تنسخ فقط ولا تنفّذ شيئًا.**

## من أين تأتي البيانات

المولّد يقرأ من Git لا من الملفات المفتوحة، فيعطي النتيجة نفسها أينما شُغّل داخل المستودع.

| ما تعرضه الصفحة | مصدره |
|---|---|
| المراحل: العناوين والأهداف والتبعيات والنطاق والنموذج والجهد | واجهة YAML في ملفات `docs/phases/` على `main` |
| الموجات وشروط بدئها وإغلاقها | جدول `docs/waves/README.md` على `main` بين علامتيه |
| الموجة الحالية وأمرها | أول موجة فيها مرحلة لم تُغلق. وأمرها «ابدأ» إن لم يبدأ فيها شيء، وإلا «تابع» |
| الحالة الحية: قيد العمل، أو تنتظر جوابك، أو معطّلة، أو سُلّمت | حالة ملف المرحلة على فرعها `phase/<ID>`، وعدد commits الفرع، ونظافة مجلده، ووجود ملف التسليم |
| ما تحتاجه مرحلة متوقفة من المالك | حقل `owner_request` في واجهة ملف المرحلة على فرعها |
| الإغلاق | الحالة `closed` على `main` مع وسم `<ID>-closed`. والمرحلة المغلقة دون وسم تظهر بتنبيه |
| القرارات التي تنتظر المالك | جدول القسم 2 في `docs/tracking/decisions.md` على `main`، مربوطًا بحقلي `owner_gates` (قبل البدء) و`owner_inputs` (أثناء المرحلة). وما حالته «مفوَّض» تحسمه الجلسة الرئيسية (ORG-13)، فلا يُعرض قرارًا على المالك ولا يوقف مرحلته، ويظهر في تفاصيلها «مفوَّض» |
| العوائق | القسم المفتوح في `docs/tracking/blockers.md` على `main` |
| تاريخ التحديث | أحدث تاريخ حالة في المراحل وفروعها وآخر قيد في سجل التقدم، ومعه لحظة التوليد والـcommit |

«جاهزة» و«تنتظر قرارك» و«تنتظر تصميمًا معتمدًا» و«تنتظر مرحلة سابقة» حالات **يحسبها المولّد** من التبعيات والقرارات، ولا تُكتب في أي ملف. واعتماد مراحل التصميم يظهر دائمًا في «سيُطلب أثناء الموجة» لأن كل مرحلة تصميم تحتاجه.

## التحديث

```bash
/opt/homebrew/bin/node tools/dashboard/build.mjs --check
```

```bash
/opt/homebrew/bin/node tools/dashboard/build.mjs
```

الأول يتحقق دون كتابة: كل مرجع إلى مرحلة أو قرار موجود، والحقول الإلزامية كاملة، وكل مرحلة في موجة واحدة، ولا مرحلة في موجة تسبق تبعيتها أو تساويها. ثم يطبع الموجة الحالية وأمرها وحالة كل مرحلة فيها وما ينتظر المالك، فيكفي لجواب «ما الحالة؟». والثاني يولّد الصفحة، ثم تُنشر على الرابط نفسه (في Claude Code: أداة Artifact بـ `url` المسجل أعلاه).
