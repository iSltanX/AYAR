# صفحة المراحل

صفحة عربية تفاعلية تعرض مراحل التصميم والتطوير وحالاتها، وما ينتظر تبعية أو تصميمًا أو قرارًا، مع زر لكل مرحلة ينسخ أمر بدئها فقط.

| البند | القيمة |
|---|---|
| الرابط المنشور | https://claude.ai/artifact/H148UTA7G6ETD1fWGKN3qE (خاص بحساب المالك، ويُشارَك من قائمة Share في الصفحة) |
| الملف المولَّد | [ayar-phases.html](ayar-phases.html) (لا يُحرَّر يدويًا) |
| المولّد | [tools/dashboard/build.mjs](../../tools/dashboard/build.mjs) |
| القالب | [tools/dashboard/template.html](../../tools/dashboard/template.html) |

## من أين تأتي البيانات

| ما تعرضه الصفحة | مصدره الوحيد |
|---|---|
| المراحل وعناوينها وأهدافها ومتطلبات بدئها ومخرجاتها وتبعياتها وحالاتها | واجهة YAML في كل ملف تحت `docs/phases/` |
| القرارات التي تنتظر المالك | جدول القسم 2 في `docs/tracking/decisions.md` بين علامتيه |
| تاريخ التحديث | أحدث `status_date` في ملفات المراحل وآخر قيد في `docs/tracking/progress.md` |
| التحقق من الإغلاق | وسوم `<ID>-closed` في Git. والمرحلة المغلقة في ملفها دون وسم تظهر بتنبيه |
| الـcommit | `HEAD` لحظة التوليد، مع ملاحظة إن كانت في المصادر تغييرات غير ملتزمة |

«متاحة للبدء» و«تنتظر قرارك» و«تنتظر تصميمًا معتمدًا» و«تنتظر مرحلة سابقة» حالات **يحسبها المولّد** من الحالة والتبعيات والقرارات، ولا تُكتب في أي ملف.

## التحديث

```bash
/opt/homebrew/bin/node tools/dashboard/build.mjs --check
```

```bash
/opt/homebrew/bin/node tools/dashboard/build.mjs
```

الأول يتحقق من المصادر دون كتابة: كل مرجع إلى مرحلة أو قرار موجود، والحقول الإلزامية كاملة، والحالات معروفة. ويفشل بقائمة الأخطاء إن وُجدت. والثاني يولّد الصفحة. ثم تُعاد بالنشر على الرابط نفسه (في Claude Code: أداة Artifact بـ `url` المسجل أعلاه). وترتيب ذلك عند إغلاق مرحلة في [AGENTS.md القسم 3.4](../../AGENTS.md).
