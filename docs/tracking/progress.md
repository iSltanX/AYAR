# سجل التقدم

سجل زمني يُضاف إليه ولا يُعاد كتابته. لكل جلسة عمل أو إغلاق مرحلة قيد. والحالة الحالية لكل مرحلة في واجهة ملفها، لا هنا.

**صيغة القيد:**

```text
## YYYY-MM-DD — <ID> — <بدء | تقدم | إغلاق | تعطل>
- المنجز: …
- الفحوص: <الفحص> → <النتيجة> (لا يُذكر فحص لم يُشغَّل إلا بعبارة «لم يُشغَّل» وسببه)
- الـcommits: <hash> <الرسالة>
- التالي: …
```
