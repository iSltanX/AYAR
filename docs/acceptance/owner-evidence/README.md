# أدلة اختبارات المالك (DEV-13)

ما أعاده المالك من [اختبارات جهاز المالك](../owner-tests.md): لقطات AT-33 وAT-41، وما قرأته الجلسة الرئيسية من مجلد بياناته (AT-13 وAT-32 وAT-33). كل ملف يحمل معرّف اختباره في اسمه، والجدول في [تقرير القبول](../AT-report.md) يحيل إليه. وقائمة VoiceOver (AT-40) ومهمة القارئ (AT-43) لم تُنفَّذا بقرار المالك، فلا ملف لهما هنا (مراجعة DEV-13 R1-13).
