# قائمة مراجعة VoiceOver ولوحة المفاتيح (AT-40، FR-53، NFR-04)

يوقّعها المالك على جهازه (Q-07). كل بند يُعلَّم ✔ إن تحقق، أو ✘ مع وصف ما حدث. تُنفَّذ على `~/Applications/AYAR.app` بالمشروع `~/AYAR-acceptance/FX-EXT`.

**التحضير:** تشغيل VoiceOver بـ ⌘F5. التنقل بـ VO (⌃⌥) مع الأسهم، والدخول إلى المجموعات بـ VO+⇧+↓.

## أ. الرحلة J1 بلوحة المفاتيح وحدها (دون فأرة ودون VoiceOver)

| # | الخطوة | المتوقع | ✔/✘ وملاحظة |
|---|---|---|---|
| 1 | ⌘O | تُفتح نافذة اختيار المجلد | |
| 2 | اختيار `FX-EXT` ثم Return | يبدأ الاكتشاف وتظهر شاشة «ما وجده عِيَار» | |
| 3 | Tab حتى «راجع ملف المعايير» ثم Return | شاشة الاعتماد، والتركيز مرئي على كل زر مررت به | |
| 4 | Tab حتى «اعتمد الكل» ثم Return | لا فحص «يحتاج اعتمادًا» باقٍ | |
| 5 | ⌘R | خطة الفحص الكامل، ثم Return على «ابدأ الفحص الكامل» | |
| 6 | أثناء التشغيل: Tab عبر صفوف المتابعة | التركيز ينتقل صفًا صفًا، والحالة مقروءة في النص | |
| 7 | بعد الانتهاء: ⌘1 | نظرة عامة، وبطاقة النقاء بحكمها | |
| 8 | Tab إلى صف اكتشاف ثم Space ثم ⇧⌘C | يُنسخ «للنموذج» وتظهر الرسالة العابرة بعدد المحارف | |
| 9 | ⌥⌘I | يظهر المفتش ويختفي | |
| 10 | ⌘, | الإعدادات، وTab يصل إلى كل مجموعة | |

## ب. دورة الإصلاح بلوحة المفاتيح

| # | الخطوة | المتوقع | ✔/✘ وملاحظة |
|---|---|---|---|
| 11 | في النتائج: Tab إلى اكتشاف «أخفق» ثم Return | يُفتح الاكتشاف في المفتش، وفيه «ماذا أفعل الآن» | |
| 12 | ⇧⌘R | نافذة «أعد الفاشل» بخاناتها؛ Return يبدأها | |
| 13 | بعد الانتهاء: Tab إلى «قارن بالتشغيل السابق» ثم Return | شاشة المقارنة: زال، وجديد، ومستمر | |
| 14 | Escape في أي نافذة مفتوحة | تُغلق النافذة ويعود التركيز إلى الزر الذي فتحها | |

## ج. VoiceOver على الرحلة نفسها

| # | ما يُستمع إليه | المتوقع | ✔/✘ وملاحظة |
|---|---|---|---|
| 15 | شاشة المشاريع الفارغة | يقرأ العنوان ووصف الحالة الفارغة واسم زر «اختر مجلدًا…» | |
| 16 | صف المشروع في الجدول | الاسم والمسار والحالة والعيار بترتيب منطقي | |
| 17 | شارة النتيجة في صف فحص | يقرأ نص الحالة («اجتاز»، «أخفق»…) لا اللون ولا الرمز وحده | |
| 18 | شارة الجاهزية | تُقرأ «جاهز» أو «يحتاج تجهيزًا» مميزةً عن النتيجة | |
| 19 | أثناء التشغيل | إعلانات حية: بدء الفحص وانتهاؤه وتغير الحكم، دون إغراق (لا إعلان لكل سطر سجل) | |
| 20 | بطاقة النقاء | يقرأ الحكم ثم العيار «من 24» ثم النطاق | |
| 21 | تبويبا «لك» و«للنموذج» | يقرأ اسم التبويب وحالته (محدد) وعددهما | |
| 22 | زر «انسخ للنموذج» | يقرأ اسمه والملاحظة الملاصقة له قبل الضغط | |
| 23 | نافذة تأكيد (مثل «أعد الفاشل») | يُعلن فتحها، والتركيز داخلها، وEscape تغلقها | |
| 24 | المفتش | يُقرأ عنوانه ومحتواه، ويصل إليه VO+→ | |
| 25 | الإعدادات: مفتاح ومجموعة اختيار وقائمة | يقرأ التسمية والقيمة الحالية ويبدّلها Space أو الأسهم | |
| 26 | تقليل الحركة (إعدادات النظام ← تسهيلات الاستخدام ← الشاشة) | المؤشرات الدوارة تصير رموزًا ثابتة مع النص | |
