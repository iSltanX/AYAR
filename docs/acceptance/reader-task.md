# مهمة القارئ غير المتخصص (AT-43، الرحلة J10، NFR-11)

**للمالك:** يعطي القارئ هذه الصفحة الأولى وحدها، ويفتح له عِيَار على شاشة النتائج لمشروع `FX-EXT` بعد الفحص الكامل، على تبويب «لك». ولا يجيب عن أي سؤال أثناء المهمة؛ إن سأل القارئ، يسجّل المالك السؤال في النموذج ويقول «أكمل كما تفهم». لا يُسجَّل اسم القارئ (Q-07). المدة لا تتجاوز عشر دقائق.

---

## الصفحة الأولى: للقارئ

أمامك تطبيق فحص مشروع برمجي، وقد انتهى من الفحص. **لست مطالبًا بفهم البرمجة**، ولا بفتح أي سجل أو ملف. اقرأ ما يعرضه التطبيق وأجب:

1. اقرأ في تبويب «لك» الأقسام الثلاثة: **ماذا حدث**، و**ماذا يعني**، و**ماذا أفعل الآن**. ثم قل بجملة واحدة: هل المشروع بحالة جيدة أم لا، ولماذا.

2. في قائمة النتائج ثلاث مشكلات معلَّمة لك بأرقامها أدناه. لكل واحدة، انظر إلى **زر الخطوة التالية** الظاهر بجوارها واختر ماذا تفعل:
   - (أ) أضغط «جهّز…» لأن شيئًا ينقص التطبيق نفسه
   - (ب) أضغط «حدّد للنسخ» ثم «انسخ للنموذج» لأرسلها إلى مساعد برمجي يصلحها
   - (ج) أضغط «راجع وقرّر» لأن القرار لي أنا

   | المشكلة | اختيارك (أ/ب/ج) | لماذا، بكلماتك |
   |---|---|---|
   | المشكلة 1: الفحص الذي فيه كلمة «يحتاج تجهيزًا» أو «ناقص» | | |
   | المشكلة 2: البند الذي «أخفق» (سر في الشيفرة) | | |
   | المشكلة 3: البند الذي فيه «يحتاج مراجعة» | | |

3. هل صادفت كلمة لم تفهمها ولم يشرحها التطبيق حين مررت عليها؟ اكتبها هنا: ____________

انتهيت. شكرًا.
