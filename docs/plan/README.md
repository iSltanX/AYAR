## قواعد التعامل مع هذه الملفات

1. **لا تُعدَّل.** أي تغيير في قرار أو متطلب يُسجَّل قرارًا جديدًا في [سجل القرارات](../tracking/decisions.md) بسببه وأثره، كما تشترط الخطة (القسم 24). البصمات في [CHECKSUMS.sha256](CHECKSUMS.sha256)، ويتحقق منها المنفّذ عند بدء كل مرحلة:

   ```bash
   cd docs/plan && shasum -a 256 -c CHECKSUMS.sha256
   ```

2. **الإحالة بالقسم.** «الخطة 3، القسم 9.12» أو «البرومبت §6.5». أرقام أقسام الخطة متصلة عبر ملفاتها الأربعة (0–28)، وأرقام البرومبت مستقلة.
3. **ما يتقدم على الخطة:** القرارات الجديدة المسجلة بعد 9 أكتوبر 2026 في سجل القرارات، فقط بقدر ما تنص عليه. أبرزها حتى الآن: اعتماد هوية النقّار بدل اتجاهات الشعار الثلاثة في البرومبت §3.2 (D-48)، ونطاق لون العُرف (D-49).
4. **ما لا تتضمنه الخطة عمدًا** (القسم 0.1): تقسيم العمل والبرومبتات. هذان في [docs/phases](../phases/README.md).
