# مواصفة المحرك (مصدر قاعدة المعرفة)

[AYAR-plan-3-engine.md](AYAR-plan-3-engine.md) هو الجزء الثالث من الخطة الأصلية لعِيَار (9 أكتوبر 2026): مسار التنفيذ، وأقسام الفحص وكتالوج الإصدار الأول، ومؤشر النقاء `purity/1`، والتقارير، وقاعدة المعرفة `kb/1` (القسم 28).

يبقى في المستودع لأنه **مصدر بيانات قاعدة المعرفة**:

- `packages/catalog/scripts/kb-extract.ts` يقرأ القسم 28 ويولّد منه ملفات `packages/catalog/data/kb/` (`node packages/catalog/scripts/kb-extract.ts --write`).
- `packages/catalog/test/kb.test.ts` يعيد التحليل نفسه ويقارنه بالملفات الملتزمة، فلا تفترق البيانات عن نصها.

فلا تعدّل القسم 28 إلا وأنت تقصد تغيير قاعدة المعرفة، ثم أعد التوليد وشغّل الاختبار.

بقية الخطة الأصلية (الأجزاء 1 و2 و4، وبرومبت التصميم) وسجلات المراحل والقرارات محفوظة في تاريخ Git عند الوسم `v0.1.1`، ومنها تأتي المعرّفات التي تذكرها تعليقات الشيفرة (مثل `FR-xx` و`NFR-xx` و`C-xx` و`D-xx` و`E-xx` و`AT-xx`).
