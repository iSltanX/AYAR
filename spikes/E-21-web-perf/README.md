# E-21 — طريقة قياس أداء الويب

**المعيار (الخطة 22):** قياس المسبار إن ثبت تكراره ضمن ±10%، وLighthouse محولًا اختياريًا إن أضاف قيمة.

**ما يُفحص:** نموذج قياس عبر المسبار (playwright-core + Chromium الخاص به) على FX-WEB-DESIGN، وتقييم Lighthouse CLI (13.5.0 مثبتًا). خمسة تشغيلات لكل طريقة، ولكل مقياس المتوسط والانحراف ومعامل الاختلاف وأقصى انحراف عن المتوسط.

## الإعادة

```bash
~/.nvm/versions/node/v24.16.0/bin/node spikes/E-21-web-perf/run.mjs    # يثبّت Lighthouse 13.5.0 في ~/.cache/ayar-dev2/lighthouse أول مرة
```

## القرار

- **قياس المسبار معتمد لـ `perf.web`** (الفرع الأول من المعيار) **بشرط التقييد**: CPU 4× ثابت في مواصفة القياس، وخمسة تكرارات يُؤخذ وسيطها، وتُبلَّغ المقاييس التي تقل عن 20 مللي ثانية أو يزيد معامل اختلافها على 10% بوسم «غير مستقر» بدل الحكم عليها. المقاييس المعتمدة: FCP وLCP وload وTaskDuration وScriptDuration وLayoutDuration وCLS والموارد والبايتات؛ وDOMContentLoaded وTTFB معلومات فقط.
- **Lighthouse محول اختياري مُدار** (أضاف قيمة: الدرجة والفرص والشبكة المحاكاة) بإصدار مثبت 13.5.0 وبـ `CHROME_PATH` إلى Chromium المسبار و`--only-categories=performance --output=json`، ولا يُضمَّن في الفحص الكامل افتراضيًّا لكلفته.
- **لا يتغير نص الخطة** (10.3 يذكر «طريقة القياس تُحسم (E-21)»).
