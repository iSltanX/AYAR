# E-16 — قراءة بيانات Git من الملفات

**المعيار (الخطة 22):** عرض ما يُقرأ بثقة، وإلا «غير معروف». ولا `git`.

**ما يُفحص:** `packed-refs`، ومساحات العمل الإضافية، والوحدات الفرعية، وصيغة SHA-256، على مستودعات المالك ومشاريع الاختبار، دون `git` (C-06، البند 8).

## الملفات

- `reader.mjs`: القارئ (ملفات فقط): `.git` مجلدًا أو ملفًا (`gitdir:` ثم `commondir`)، و`HEAD` (رمزي أو منفصل)، والمراجع الفضفاضة ثم `packed-refs`، و`extensions.objectFormat`، و`worktrees/*`، و`.gitmodules` مع `.git` في مجلد الوحدة، و`shallow`، وآخر قيد في `logs/HEAD` للمقارنة، والريموت للعرض. يقرأ من `config` مفاتيح معلومة بتعبير نمطي ولا ينفذ شيئًا، ولا يقرأ الكائنات ولا الحزم. يُستعمل: `node reader.mjs <root>`.
- `run.mjs`: الاختبار على 9 مستودعات اصطناعية (git مسموح في المجلد المؤقت)، ومجلد عمل DEV-2، وFX-MALICIOUS المولَّد (بلا git)، ومستودعات المالك الثلاثة (بلا git، مع جرد `.git` قبل وبعد).

## الإعادة

```bash
~/.nvm/versions/node/v24.16.0/bin/node spikes/E-16-git-from-files/run.mjs    # النتائج في results/run.json
```

## القرار

- **القراءة من الملفات تكفي للعرض والتعريف** في كل الحالات المطلوبة (packed-refs ومساحات العمل والوحدات الفرعية وSHA-256 والسطحية)، وتطابق `git` حيث جازت المقارنة. والثقة «مؤكد» حين يُحل HEAD إلى التزام، و«غير معروف» بسبب مكتوب (مستودع جديد، أو مرجع مفقود، أو HEAD غير مفهوم، أو حلقة رموز).
- **ما يُعرض:** الفرع أو «HEAD منفصل»، والالتزام بطوله الكامل (40 أو 64)، وصيغة الكائنات، و«مساحة عمل مرتبطة بـ …»، وقائمة الوحدات الفرعية بحالة تهيئتها، و«مستودع سطحي» (يذكره `sec.secrets.history` في نتيجته كما ينص الكتالوج)، ومضيف الريموت للعرض فقط.
- **لـ DEV-4 (C-06):** يُنقل `reader.mjs` أساسًا للكاشف مع اختباراته، ويُضاف تطبيع `core.worktree` وملفات `.git` ذات `gitdir` المطلقة حين تظهر. **لا يتغير نص الخطة.**
