# E-24 — فحص تاريخ Git دون تنفيذ إعدادات المستودع

**المعيار (الخطة 22):** مستودع ظلي يعطي نتائج الفاحص نفسها على النظيف ولا ينفذ شيئًا على المفخخ. وإلا قراءة الكائنات بمكتبة لا تنفذ الإعدادات وتمرير المحتوى إلى الفاحص عبر الإدخال القياسي. وإن تعذر الاثنان يبقى الفحص خارج الإصدار الأول (ويتغير AT-42).

**ما يُفحص:** على FX-MALICIOUS المولَّد ومستودع نظيف معروف (النسخة `--no-traps` نفسها): بناء المستودع الظلي، وتشغيل الفاحص عليه ببيئة Git معزولة (`GIT_CONFIG_NOSYSTEM=1` و`GIT_CONFIG_GLOBAL=/dev/null`)، والتحقق من عدم إنشاء ملفات العلامة، ومقارنة النتائج بتشغيل الفاحص المعتاد على النظيف.

## الإعادة

```bash
~/.nvm/versions/node/v24.16.0/bin/node spikes/E-24-git-history-shadow/run.mjs    # النتائج في results/run.json
```

## النتائج (2026-10-10، Git 2.54.0 (Apple Git-157)، Betterleaks 1.9.0، Gitleaks 8.30.1)

### 1. الظلي

يُبنى **بملفات فقط** (لا أمر git على المفخخ): مجلد عارٍ فيه `HEAD` منسوخ، و`refs/` منسوخة (و`packed-refs` إن وُجد)، و`objects/info/alternates` يشير إلى `<المفخخ>/.git/objects`، و`config` من سطرين (`bare = true` و`repositoryformatversion = 0`)، ولا `hooks/` ولا `info/attributes` ولا `index`.

## القرار

- **المستودع الظلي يحقق المعيار** (الفرع الأول): النتائج مطابقة حرفيًّا للتشغيل المعتاد على النظيف، وصفر ملفات علامة، وصفر استدعاء git على المفخخ، وصفر كتابة فيه. والضابط الإيجابي يثبت أن الفحص المباشر ينفذ `textconv` من إعداد المستودع، فالحماية ضرورية لا احتياطية.
- **يبقى `sec.secrets.history` في الإصدار الأول** (لا يتغير AT-42 ولا تعريف الاكتمال 25). وصياغته في C-15: الظلي في المجلد المؤقت للمثيل، ببيئة `GIT_CONFIG_NOSYSTEM=1 GIT_CONFIG_GLOBAL=/dev/null GIT_ATTR_NOSYSTEM=1 GIT_TERMINAL_PROMPT=0`، ثم `<tool> git <shadow> --redact=100 --no-banner --report-format json --report-path <r>/secrets.json --exit-code 42`، ثم حذف الظلي. وفي AT-42 يُثبت تتبع العمليات أن كل استدعاء git يشير إلى الظلي.
- **ملاحظتان:** (1) الظلي يحتاج Git النظام (موجود: `/usr/bin/git` من Xcode)؛ غيابه «ناقص» للفحص وحده. (2) المستودع السطحي يُفحص تاريخه المتاح، وتُنسخ `shallow` معه إلى الظلي ليعرف git حدوده.
- **لا يتغير نص الخطة.**
